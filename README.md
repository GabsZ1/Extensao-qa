# 🧪 Extensão QA - Testes Manuais

Repositório dedicado ao estudo, prática e documentação de testes manuais de software, desenvolvido na disciplina de Extensão - Qualidade de Software (UniALFA), com foco em:

* Aprendizado de QA
* Organização de casos de teste
* Melhoria contínua na análise e cobertura de testes

## 🎯 Objetivo

Este projeto foi criado com o objetivo de:

* Consolidar conhecimentos de testes manuais
* Simular testes em um sistema real (SIFIT - Sistema para Academias)
* Criar um portfólio técnico bem estruturado para futuras oportunidades profissionais

## 🧱 Estrutura do repositório

A estrutura está organizada por pastas, cada uma representando um sistema testado:

📁 **SIFIT**
↳ Análise de Requisitos, Plano de Testes, Cenários e Casos de Teste, Relatório de Bugs e Relatório Final

```
SIFIT/
├── 1-Analise de requisitos.md
├── 2-plano de testes.md
├── 3-Relatorio-de-Bugs.md
├── 4- Relatorio dos testes.md
└── Cenarios de testes/
    ├── CT_RF01_ Login na plataforma.md
    ├── ...
    └── CT_RF10_ Geração de relatórios.md
```

## 🧪 Metodologia

* **Técnicas aplicadas:** Testes Positivos, Negativos, Exploratório, Funcional
* **Ferramentas:** Google Chrome, DevTools, Jam (vídeos de evidência), MySQL Workbench, Markdown, GitHub
* **Formatos:** BDD (Gherkin), Tabelas e Checklist
* **Processos:** Planejamento de Teste, Execução e Relatório
